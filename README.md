# Consultor Frontend

App móvil desarrollada con React Native (Expo) para el sistema de consultoría.

## 📱 Pantallas

- **Splash Screen**: Pantalla de bienvenida con logo
- **Login Screen**: Inicio de sesión (C.I y Password)
- **Home Screen**: Menú principal con 3 opciones
- **Funciones Screen**: Conocer Proveedores y Obligaciones
- **Herramientas Screen**: Herramientas disponibles
- **Contacto Screen**: Información de contacto

## 🚀 Instalación

```bash
npm install
npm start
