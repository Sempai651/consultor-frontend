## 📱 **Pantallas**

| # | Pantalla | Descripción |
|:-:|----------|-------------|
| 1 | **Login** | Inicio de sesión con cédula y contraseña |
| 2 | **Registro** | Creación de nueva cuenta |
| 3 | **Recuperar Clave** | Recuperación de contraseña por email |
| 4 | **Home** | Dashboard con resumen y accesos rápidos |
| 5 | **Funciones** | Gestión de proveedores y obligaciones |
| 6 | **Herramientas** | Calculadoras y utilidades empresariales |
| 7 | **Contacto** | Información de contacto |

---

## ✅ **Validaciones**

| Campo | Requisito |
|-------|-----------|
| **Cédula** | 10 dígitos, solo números, algoritmo ecuatoriano |
| **Contraseña** | 8+ caracteres, mayúscula, minúscula, número, carácter especial |
| **Email** | Formato válido (ejemplo@correo.com) |
